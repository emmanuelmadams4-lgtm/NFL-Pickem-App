Design (all frozen by the tests):
* `router = APIRouter(prefix="/api")`. One route `@router.get("/news", response_model=NewsOut)`, sync `def`, session via `Depends(get_session)`.
* Models (names matter, they appear in openapi): `NewsItemOut(title: str, source: str, published_at: datetime | None, url: str | None, tags: list[str])`, `NewsOut(game_id: str, items: list[NewsItemOut])`. Exactly those keys, with a short `Field(description=...)` on each (source = display name; url = null when not a safe https link on the item's own source host; published_at null when the feed gave none).
* `game_id: str | None = None` as a PLAIN query parameter (no Query pattern: FastAPI's own 422 would echo the value). Check by hand with `re.fullmatch(r"[A-Za-z0-9_-]{1,32}", game_id)` (None fails too). On failure raise `HTTPException(422, "game_id must be 1 to 32 letters, digits, - or _")` (same text always; never include the value). Look the game up with `session.get(Game, game_id)`; none -> `HTTPException(404, "Game not found")`. Echo `game.game_id` from the row.
* Items query, ALL in SQL before the limit: `select(NewsItem).where(NewsItem.source.in_(known source ids from sources.SOURCES), or_(cast(NewsItem.team_ids, JSONB).contains([game.home_team]), cast(NewsItem.team_ids, JSONB).contains([game.away_team]))).order_by(NewsItem.published_at.desc().nulls_last(), NewsItem.fetched_at.desc(), NewsItem.id.desc()).limit(5)`. `team_ids` is a JSON column (not JSONB): the cast is required (`from sqlalchemy.dialects.postgresql import JSONB`); values are bound, never string-formatted. Keep MAX_ITEMS = 5 a named constant.
* Per item, untrusted text, in this order: `title = parse.clean_text(row.title, 200)` FIRST, then remove every `<` and `>` LAST, then collapse whitespace and strip (nothing may decode after the removal); skip the item if the title is empty after that. `source` = the Source's `name` (fall back to its id). `tags` = sorted tags of the row that are in `("coach", "injury", "playcaller", "trade")`, nothing else. `url` = `parse.canonical_url(row.url_canonical, src.link_suffixes)` where `src` is the item's OWN source (so another allowlisted host on this item is null); do not alter it afterwards. `published_at` = the row value untouched (null stays null).
* Read only. No network. No logging of titles or urls.
